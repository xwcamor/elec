# Guía de diseño de ChatGPT — Proyecto ELEC

Este archivo contiene instrucciones de trabajo para las conversaciones de ChatGPT Go relacionadas con el repositorio ELEC.

Cuando trabajemos en ELEC y la tarea incluya interfaz, CSS, JavaScript visual, componentes, formularios, navegación o animaciones:

1. Consulta y sigue .agents/skills/emil-design-eng/SKILL.md en el repositorio.
2. Aplica esa guía solo a ELEC; no la conviertas en una preferencia global.
3. Antes de modificar, inspecciona los archivos y patrones actuales.
4. No cambies reglas de negocio, fórmulas eléctricas, validaciones ni persistencia durante una tarea visual, salvo que se solicite.
5. Prioriza una interfaz técnica, coherente, accesible y rápida en equipos modestos.
6. Al terminar, informa archivos modificados, pruebas ejecutadas y aspectos pendientes.

Nota: ChatGPT Go en el navegador no carga automáticamente los archivos del repositorio. Para usar esta guía en una conversación nueva, pide que se consulte este archivo y la skill desde GitHub o adjúntalos a la conversación.
