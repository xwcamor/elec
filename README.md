# ELEC

Proyecto demo independiente.

## Requisitos
- PHP 8.3 o superior
- Laragon (Apache o Nginx)

## Ejecución local
1. Clonar este repositorio dentro de `C:\laragon\www\elec`.
2. Iniciar Laragon.
3. Abrir `http://elec.test` si tienes configurado el auto virtual host, o `http://localhost/elec`.

## Estructura
```
elec/
├── assets/
│   ├── css/
│   │   └── app.css
│   └── js/
│       └── app.js
├── index.php
└── README.md
```

La aplicación todavía no define módulos de negocio; esta es únicamente la base inicial.
